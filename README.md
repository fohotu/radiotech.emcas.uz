# RadioTerm

RadioTerm is a multilingual terminology platform for radio-frequency spectrum, radiocommunication, telecommunications, and ITU standards.

## Features

- Search and browse technical terms
- Definitions in Uzbek, Russian, and English
- Categories and related terms
- References to official sources and recommendations
- Admin panel for terminology management (planned)

## Tech Stack

- Laravel
- Inertia.js
- React
- Tailwind CSS
- MySQL (planned)
